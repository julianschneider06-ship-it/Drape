Original background images go here, named `<season>-<family>-<1|2|3>.<png|jpg>` (for example `winter-street-2.png`) or `neutral-<1|2|3>.<ext>`. The originals stay untouched; `npx tsx scripts/add-backgrounds.ts` converts them to `public/backgrounds/*.webp` and regenerates `src/config/background-manifest.json`.
